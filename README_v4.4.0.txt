ZUKKA KEY v4.4.0

主な変更
- 音域取得を「保存済み → 無料WEB検索 → 予備の有料Search API → 手入力」の順に変更
- 音域サイトへCORSで直接アクセスできる場合はJinaを使わず直接取得
- 直接取得できない時だけ、APIキー不要のReader経由で対象ページを読む
- Jina Search APIは予備に降格。残高不足でも無料検索は次の曲で引き続き動作
- 同じ曲の取得済み音域は端末保存し、以後WEB検索しない
- 曲名＋アーティスト一致を継続し、カバー曲取り違えを防止
- 音域未取得時は推奨キーを出さず「音域待ち」を維持

注意
無料WEB検索は外部サイトや検索結果の仕様変更で取得できない場合があります。
その場合もキー/BPMは残り、予備検索APIまたは手入力で続行できます。

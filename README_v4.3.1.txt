ZUKKA KEY v4.3.1

今回の修正
- 音域未取得なのに「ずっか判定 ±0」と表示される状態を修正。未取得時は必ず「音域待ち」。
- 新規曲の音域欄を未入力から開始し、初期値を実データと誤認しないよう変更。
- サビ高音・地声最高音・最低音が未入力ならおすすめ判定を実行しない。
- Jina 402/残高不足時は全曲共通で12時間WEB音域検索を抑制し、無駄な再試行を防止。音域API設定を再保存すると即時解除。
- Jina失敗/未設定/一致なし時も、キー/BPMを保持しつつ判定表示は「音域待ち」に固定。
- Service Worker / asset versionを4.3.1へ更新。

推奨確認
1. たそがれマイ・ラブ / 徳永英明 を検索
2. Jina利用上限中でも Em / 106 は残る
3. 音域データ=未登録、ずっか判定=音域待ち になる
4. 手動でサビ高音・地声最高音・最低音を入れると「判定待ち」になり、ボタンで推奨キーが出る

# ZUKKA KEY

個人向けカラオケ・キー判定PWA。

## 使い方
1. HTTPSでこのフォルダを公開（GitHub Pages / Netlify / Cloudflare Pages 等の静的ホスティング）。
2. iPhoneのSafariでURLを開く。
3. 共有 → ホーム画面に追加 → 「Webアプリとして開く」をオン。

## 特徴
- サビでよく使う高音、地声・ミックス最高音、ファルセット、最低音、高音密度から推奨キーを算出
- 「最高音だけ」を基準にせず、一瞬の裏声/フェイクを別扱い
- 歌唱ログをiPhone内のlocalStorageへ保存
- 実測評価4〜5の曲を次回判定に反映
- JSONバックアップ/復元
- オフライン対応（Service Worker）

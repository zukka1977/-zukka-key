ZUKKA KEY v4.3.0

主な改善
1. Jina 402（残高不足）/429/タイムアウト/通信障害を分類し、長い生エラーを画面に出さない。
2. Jinaが失敗してもGetSongで取得済みの「歌手版キー/BPM」を残し、手入力で判定を続行できる。
3. 保存済み音域・手動確認済み音域を最優先。再検索しないためJina消費を削減。
4. WEB検索を最大4〜5クエリに削減し、高信頼ソースが見つかった時点で早期終了。
5. 曲名だけ一致した別歌手版を自動採用しない。曲名＋アーティスト一致を必須化。
6. WEB音域も曲名＋アーティストが近接して確認できる候補だけ採用。低信頼の汎用解析は自動採用しない。
7. 実測歌唱ログの重みを強化。同一曲の高評価実測は従来どおり最優先。
8. Service Workerを堅牢化。任意ファイルが欠けてもSWインストール全体が失敗しない。
9. 旧 hotfix.js / predictor-tune.js / updater.js の読み込みを外し、古い上書きロジックとの競合を防止。

更新方法
- index.html / styles.css / app.js / range-lookup.js / sw.js をサーバー上の同名ファイルと置き換えてください。
- manifest.webmanifest と各iconは今回のZIPには含まれていません。既存サーバー上のものをそのまま使用します。
- iPhoneで更新が反映されにくい場合はSafariで一度ページを再読込してからホーム画面版を開いてください。

注意
- 外部APIの実キーを使った本番通信テストはこの環境では実施していません。
- JavaScript構文チェックは app.js / range-lookup.js / sw.js すべて通過済みです。

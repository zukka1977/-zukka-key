ZUKKA KEY v4.4.2

主な変更
- 無料音域ソースに KeyTube を追加
- 「徳」と「德」、「高」と「髙」など一部の異体字を正規化し、正しい歌手版が検索結果から弾かれる問題を修正
- KeyTube の「最低音 / 最高音 / 最頻音」を読み取り、音域候補として利用
- KeyTube が未監修データの場合は信頼度を一段下げて採用し、過信しない設計
- 無料検索を最大4経路に拡張。ただし高信頼候補が見つかれば即終了
- 保存済み → 無料WEB → 予備Search API → 手入力、の順は維持
- 音域未取得時は引き続き「音域待ち」で誤判定しない

今回の確認曲
「たそがれマイ・ラブ / 徳永英明」は、公開検索では KeyTube に徳永英明版の音域データがあります。
KeyTube側の表記が「德永英明」になる場合があるため、v4.4.2では同一人物として照合します。

注意
無料WEB検索は外部サイトや検索結果の仕様変更で取得できない場合があります。
その場合もキー/BPMは残り、予備検索APIまたは手入力で続行できます。


v4.4.2追加
- Bing検索より先にKeyTube自身の公開検索ページを確認する方式へ変更
- Jina Readerが返す相対リンク /song/detail/12345 を絶対URLへ変換
- 検索ページから候補曲URLを拾い、各詳細ページで曲名＋歌手を再確認してから採用
- KeyTube内検索で候補が取れない場合だけ従来の補助WEB検索へフォールバック
- たそがれマイ・ラブ / 徳永英明 のようなカバー違いが多い曲でも、歌手一致を維持
